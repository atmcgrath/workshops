## Tools and platforms

### Digital scholarship publication

- [CollectionBuilder](https://collectionbuilder.github.io/) - open-source static digital exhibit tool (Jekyll)
- [Quire](https://quire.getty.edu/) - static digital book or edition tool, created and maintained by the Getty
- [Ed](https://minicomp.github.io/ed/) and [Wax](https://minicomp.github.io/wiki/wax/) -  open-source tools for static digital editions and digital exhibitions, respectively, both using Jekyll and created by [minicomp](https://minicomp.github.io/wiki/)
- [Juncture](https://www.juncture-digital.org/) - open-source visual essay tool created by JSTOR Labs
- [Canopy IIIF](https://canopy-iiif.github.io/app/) - open-source static digital exhibition/essay tool from IIIF manifests and markdown

### Other tools and platforms

- [Pandoc](https://pandoc.org/) - open-source CLI application for converting between document formats (including from Markdown to HTML, docx, pdf, and more)
- [Quarto](https://quarto.org/) - open-source tool for building static OERs, computational notebooks, and other simple websites
- [Neocities.org](https://neocities.org/) - free static webhosting, featuring HTML tutorials and discoverability options
- [Obsidian](https://obsidian.md/) - free (for local use) markdown-based knowledge management tool with database-like features 
- [Twine](https://twinery.org/) - open-source tool for creating static text-based games and nonlinear stories (uses WYSIWYG editor and simple markup)
- [Simply Static](https://wordpress.org/plugins/simply-static/) - WordPress plugin to export a WP site as static HTML
- Open-source static website frameworks: [Jekyll](https://jekyllrb.com/), [Build Awesome (aka Eleventy)](https://www.11ty.dev/), [Hugo](https://gohugo.io/), [Gatsby](https://www.gatsbyjs.com/docs/glossary/static-site-generator/), [VuePress](https://v2.vuepress.vuejs.org/), [Pelican](https://getpelican.com/)

## Projects

- [Digital Grainger: An Online Edition of *The Sugar-Cane* (1764)](https://digital-grainger.github.io/grainger/) - minimal edition of James Grainger's *The Sugar-Cane* created using Ed by Julie Chun Kim, Cristobal Silva and colleagues at Fordham and Columbia.
- [Recusant Readers: Reading with the Finches of Mawdesley](https://cchenovick.github.io/Recusant-Readers/) - digital collection created using CollectionBuilder by Stonyhurst College Historic Libraries.
- [Transpacific Crossings: Art, Trade, and the Manila Galleon](https://mayer2024.denartmus.org/), edited by Jorge F. Rivas Pérez, Karina H. Corrigan, and Kathryn Santner, symposium papers from 2024 symposium at the Denver Art Museum focused on Spanish colonialism and trade from 1565-1815. Created using Quire.
- [Plant Humanities Lab](https://lab.plant-humanities.org/) - visual essays created using Juncture by Dumbarton Oaks.
